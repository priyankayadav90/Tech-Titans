# MEGAMART-O-RAMA!!! — The World's Worst E-Commerce Site (React + Vite)

## Run it in VS Code
1. Install Node.js (https://nodejs.org) if you do not have it.
2. Open this folder in VS Code (File > Open Folder).
3. Open the terminal (Ctrl + ` ) and run:

   npm install
   npm run dev

4. Open the link it prints (usually http://localhost:5173).

## Build for production
   npm run build
